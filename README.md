Responsive Portfolio Website

A modern, clean, and fully responsive personal portfolio website
built with HTML5, CSS3, and JavaScript. This project is designed to
showcase a developer's skills, projects, services, experience, and
contact information with a professional and interactive user interface.

✨ Features

📱 Fully responsive design

🧭 Responsive navigation bar

🍔 Mobile hamburger menu

🏠 Modern hero/home section

⌨️ Typing text animation

👨‍💻 About section

🛠️ Skills and progress bars

💼 Projects/portfolio section

🔍 Project filtering

💡 Services section

💬 Testimonial slider

📩 Contact form with validation

🌙 Dark/light mode toggle

📜 Scroll reveal animations

🔗 Active navigation link

⬆️ Scroll-to-top button

⏳ Loading screen animation

✨ Smooth hover effects and transitions

💻 Clean and reusable code

⚡ Lightweight and fast

🛠️ Technologies Used

HTML5

CSS3

JavaScript

CSS Flexbox

CSS Grid

CSS Media Queries

CSS Animations

JavaScript DOM Manipulation

Font Awesome
